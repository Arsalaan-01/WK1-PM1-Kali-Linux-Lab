# WK1-PM1 Kali Linux Lab Setup

A practical lab environment built using Oracle VirtualBox and Kali Linux for network configuration, connectivity testing, and shared-folder access.

## Project Overview

This repository documents the setup of a Kali Linux virtual machine using VirtualBox with NAT Network configuration.

## Lab Configuration

- **Virtualization:** Oracle VirtualBox
- **Attacking Machine:** Kali Linux
- **Network Type:** NAT Network
- **IPv4 Subnet:** `10.0.0.0/24`
- **Shared Folder:** Downloads
- **Additional VM:** Windows 10 (for optional connectivity testing)

## Tasks Documented

- VirtualBox installation and VM configuration
- NAT Network setup
- Kali Linux network configuration
- Shared clipboard and drag-and-drop settings
- Shared-folder configuration
- IP address verification
- Network discovery using Nmap
- Windows-to-Kali connectivity testing
- Kali Linux snapshot creation
